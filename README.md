# Task_Garage

Visibility manager

Демонстративный проект функции Interact в UE5.6 на Blueprints.

Управление: LMC - клик по гнездам

Использование: На карте уже расставлены объекты. При нажатии на гнеждо появляется курица

BP_Manager: 
MoveTime - время которое нпс идет прямо
StopTime - время которое нпс стоит 
BackTime - время которое нпс идет обратно

Требования: Наличие UE5.6 FAQ

Зачем вы разработали этот проект?

Выполнение тестового задания

Задача: Реализация должна быть в 3D. Все ассеты (модели, звуки, текстуры), кроме кода и блюпринтов, можете брать из любых открытых источников. Необходимо использовать принципы ООП, соблюдать стилизацию кода, блюпринты должны быть удобочитаемыми.
